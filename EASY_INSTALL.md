# Easiest installation

The preferred end-user build is the Windows installer:

1. Download `QuotexVisionAI-Setup.exe`.
2. Double-click it.
3. Click Next -> Install.
4. Launch `Quotex Vision AI` from the desktop shortcut.
5. Open Quotex before starting the app.

No Python, pip, virtual environment, or command line is required when using the packaged EXE installer.

## Developer build

If you are building from source instead, run `Install.bat`, then double-click `run_app.bat`.
